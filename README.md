# Quantium Data Analytics Simulation – Forage

I recently completed the **[Quantium Data Analytics Virtual Experience](https://www.theforage.com/simulations/quantium/data-analytics-rqkb)** on Forage. ☑️

This hands-on program simulated real-world **Data Analytics and Commercial Insights** challenges faced by Quantium’s data science team.

## 📌 Key Highlights

* **Data Preparation & Customer Analytics:** Cleaned and explored transaction-level datasets to uncover purchasing patterns and segment customer cohorts.
* **Uplift Testing & Benchmark Stores:** Applied statistical techniques to identify control stores for trial store layout changes and measured their impact on customer behaviour.
* **Actionable Insights:** Compiled findings into data-driven recommendations to guide the Category Manager in evidence-based decision-making.

## 📂 Code Included

* **Task 1:** Data preparation and customer analytics.
* **Task 2:** Benchmark store selection and uplift testing.
